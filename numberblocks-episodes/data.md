# Numberblocks 各集列表

資料來源：[List of Numberblocks episodes — Numberblocks Wiki](https://numberblocks.fandom.com/wiki/List_of_Numberblocks_episodes)（透過 MediaWiki API 擷取，2026-07-11）

## 說明

- **No.**：全劇集數（整體累計）。Series 6 之後括號內數字 `(N)` 為「含 Numberblocks × Alphablocks crossover 特別篇」的累計集數。
- **Ep.**：該季內的集數。
- **Lvl.**：課程等級（Level 1–5）。
- 標題後 **♫** 表示該集含歌曲（`♫x2` / `♫x4` 表示多首）。
- 標題後 **𝔽** 表示該集有 Numberblock 被「figured-out」（首次成形登場）。
